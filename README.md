## 中文

啾啾是一款 macOS 和 Windows 桌面观鸟应用。像素小鸟从屏幕外飞来，在窗口顶沿歇脚、眨眼、理羽，陪你工作。

### 有什么好玩的

- **120 种鸟**：根据真实鸟种制作像素外形与习性，默认出现权重面向中国全国范围。详见下方[鸟种列表](#鸟种列表)。
- **与桌面窗口互动**：小鸟会在窗口边缘停留，跟随缓慢移动的窗口，快速拖动时可能受惊飞走；前方窗口会遮住后方的小鸟。支持多屏，也能在 Dock 或任务栏上方歇脚。
- **观鸟模式**：鼠标移到鸟身上出现取景框，点击即可记录。同一只鸟每次到访只记一次，首次发现会显示“加新！”并飘落彩色纸屑。观鸟记录保存各鸟种的累计次数与首次发现日期，未发现鸟种以剪影隐藏名称，等待你逐一发现。
- **打造自己的鸟群**：调整鸟群数量与全局尺寸；关闭观鸟模式后，还可自定义各鸟种的出现概率与参数。观鸟模式使用默认鸟种设置，关闭后恢复你的自定义配置，已有记录仍会保留。

### 开始观鸟

**Windows：** 下载并运行对应架构的 `setup.exe` 安装包。若缺少 .NET 10 桌面运行时，安装器会提示并联网下载；已有兼容运行时时直接安装。支持 Windows 10/11 x64 和 Windows 11 ARM64。从 v0.7.0 或更早版本升级，需手动运行一次新安装器，设置和观鸟记录会保留。

**macOS：** 下载并解压 ZIP，将 `ChirpOS.app` 拖入“应用程序”后打开。下载版适用于 macOS 13 及以上的 Apple Silicon Mac。

新安装或从旧版升级后，首次启动会默认开启观鸟模式并显示简短介绍；之后会记住你的开关选择，可随时从菜单关闭。

启动后稍等片刻，小鸟就会陆续飞入。点击 macOS 菜单栏或右键点击 Windows 系统托盘中的小鸟图标，即可调整设置或退出。Windows 图标可能位于托盘的隐藏图标区域。更新前请先退出正在运行的版本。

启动时发现新增鸟种，会询问是恢复所有默认概率、按新旧鸟种数量比例分配，还是保留原概率并手动设置。手动模式会直接定位到第一种新鸟；按数量分配会缩放锁定项，但保留锁定状态。体型按成年鸟代表体长进行非线性缩放（红耳鹎 1×、苍鹭 2.5×），部分配色采用雄鸟或繁殖羽；动作经过像素化简化。

macOS 版本使用 Developer ID 签名并经过 Apple 公证。Windows 版本尚未使用发布者证书签名，首次打开可能遇到系统安全提示。

### 隐私与反馈

啾啾在本机运行，仅读取窗口位置、前后顺序和用于悬停识别的鼠标位置，不读取窗口标题或内容，也不上传窗口信息或个人设置。自动更新会连接 GitHub 检查版本并下载官方安装包。窗口遮挡按矩形估算，透明窗口、圆角和特殊系统界面的效果可能有所不同。

遇到问题或有新点子，欢迎提交 [Issue](https://github.com/billtt/chirp-os/issues)。想自己构建或贡献代码，请看[开发指南](docs/DEVELOPMENT.md)。

## English

ChirpOS brings pixel-art birds to your macOS or Windows desktop. They fly in from offscreen, perch on window edges, blink, and preen while you work.

### Features

- **120 bird species:** Pixel-art designs and behaviors inspired by real birds, with default arrival weights reflecting birds across China. See the [species list](#bird-species) below.
- **Desktop window interaction:** Birds perch on window edges, follow gently moved windows, and may startle when dragged quickly. Foreground windows hide birds behind them. Multiple monitors and perches above the Dock or taskbar are supported.
- **Birdwatching mode:** Hover over a bird to bring up a viewfinder, then click to record it. Each bird counts once per visit; a newly discovered species gets a “New!” message and confetti. Your Life List keeps observation counts and first discovery dates, while undiscovered species remain unnamed silhouettes for you to discover.
- **Your own flock:** Adjust flock size and overall bird size. With birdwatching mode off, customize individual species probabilities and parameters too. Birdwatching mode uses default species settings; switching it off restores your preferences and keeps your observations.

### Get started

**Windows:** Download and run the `setup.exe` installer for your architecture. If .NET 10 Desktop Runtime is missing, Setup offers to download it; compatible existing runtimes are reused. Supports Windows 10/11 x64 and Windows 11 ARM64. To upgrade from v0.7.0 or earlier, run the new installer manually once. Settings and observations are preserved.

**macOS:** Extract the ZIP, move `ChirpOS.app` to Applications, and open it. The download supports Apple Silicon Macs running macOS 13 or later.

Birds begin arriving shortly after launch. Use the macOS menu bar icon or right-click the Windows tray icon for settings and quit. The Windows icon may be in the hidden-icons area. Quit the running version before updating.

New installations and upgrades from versions without the introduction start in birdwatching mode and show a brief introduction once. Later launches remember your choice; turn the mode off anytime from the menu.

When new species are detected at startup, choose default probabilities, allocation by species count, or manual configuration. Manual mode jumps to the first new species. Count-based allocation scales locked values but retains their lock state. Sizes use compressed adult-length ratios (bulbul 1×, Grey Heron 2.5×); some designs show males or breeding plumage, with stylized pixel animation.

The macOS app is Developer ID-signed and notarized by Apple. Windows builds are not publisher-signed, so a system security prompt may appear on first launch.

### Privacy & feedback

ChirpOS runs locally. It reads window geometry, stacking order and pointer position for hover identification, not window titles or content, and never uploads window information or personal settings. Automatic updates contact GitHub to check releases and download official packages. Occlusion uses rectangular bounds; transparent windows, rounded corners, and special system views may look different.

Report a bug or suggest an idea in [Issues](https://github.com/billtt/chirp-os/issues). For building and contributing, see the [development guide](docs/DEVELOPMENT.md).
