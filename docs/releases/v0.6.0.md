## 中文

- 新增自动更新：后台检查、下载并校验官方安装包，通过带应用名称的通知、图标红点和菜单提示更新。确认后安装并重启，保留设置，并在新版启动失败时回滚。
- 鸟种设置支持分别调整体长、振翅频率、飞行速度及最短／最长停留时间；图鉴支持手动预览动作。
- 优化飞行姿态、随机滑翔和停留节奏，让鸟群动作更自然。
- 新增 macOS Dock、Windows 任务栏上方的地面停留。
- 新增隐藏调试页：在设置内容区右上角空白处双击两次（间隔不超过 3 秒），点击“调试 → 模拟有更新”，即可预览通知、红点和确认框。确认安装会结束模拟，不会实际更新或重启。

### 下载与升级

- macOS Apple Silicon：`ChirpOS-0.6.0-macOS-arm64.zip`，macOS 13+，Developer ID 签名及 Apple 公证。
- Windows ARM64：`ChirpOS-0.6.0-win-arm64.zip`。
- Windows Intel / AMD x64：`ChirpOS-0.6.0-win-x64.zip`。

从 v0.5.0 或更早版本升级，请退出旧应用后手动下载并替换；本版开始提供自动更新功能。Windows 解压后运行 ChirpOS.exe，无需另装 .NET，程序仍未使用发布者证书签名。

更新检查继续使用 GitHub API。共享出口 IP 的匿名请求额度耗尽时可能暂时返回 HTTP 403，应用会按现有策略重试；本版未调整限流处理。

验证：84 项 macOS 核心测试、850 项 Windows 核心检查、17 项更新界面检查、37 项设置界面检查、11 项发布流程检查及跨平台鸟种数据一致性检查通过。Windows 原生桌面交互尚未实测。

## English

- Adds automatic updates with background checks, verified downloads, app-named notifications, an icon badge and installation confirmation. Updates preserve settings and roll back if the new version fails to start.
- Adds per-species body length, wingbeat frequency, flight speed and perch-duration settings, plus manual action previews in the field guide.
- Refines flight poses, randomized soaring and perch timing.
- Adds ground perching above the macOS Dock and Windows taskbar.
- Adds a hidden Debug page: double-click twice within three seconds in the upper-right blank area of settings, then choose Debug → Simulate update. Preview the notification, badge and confirmation dialog without installing or restarting.

To upgrade from v0.5.0 or earlier, quit the old application and manually download and replace it. Automatic updating is introduced in this release. The Apple Silicon macOS build is Developer ID-signed and notarized. Windows ARM64 and x64 ZIPs are self-contained; extract and run ChirpOS.exe. Windows binaries remain unsigned.

Update checks still use the GitHub API. Exhausted anonymous quotas on a shared outbound IP can temporarily return HTTP 403; the existing retry behavior is unchanged.

Validation: 84 macOS core tests, 850 Windows core checks, 17 update UI checks, 37 settings UI checks, 11 release preflight checks and cross-platform species parity checks passed. Native Windows desktop interaction has not been tested.
