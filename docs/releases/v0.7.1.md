# 啾啾 v0.7.1

- 观鸟模式下快速双击同一只鸟，会从头顶冒出三颗爱心，先原地弹出，再上浮消失。已有鸟名标签会立即移到刚冒出的爱心上方，继续原来的上浮动画；连续点击不再重复生成标签。
- 扩大鸟的点击区域，改善小体型鸟的点击体验；修复屏幕上沿的鸟名标签和点击效果偏移，以及 Windows 爱心与标签的层级闪烁。
- 观鸟记录新增“加新时间”和“记录数量”排序 Tab；再次点击切换升降序，箭头显示当前方向，未记录鸟种始终排在最后。
- 英文首次记录提示改为“Lifer”，并与鸟名增加分隔。
- 优化鸟类轮廓、羽色纹路和飞行体态，改善大体型鸟偏胖的问题；修复落地收翼时同时显示收拢和展开翅膀，以及赤麻鸭等鸟种飞行时脚部缺失的问题。
- 盘旋改为偶尔触发，并限制为最多两圈。
- Windows 改用小体积安装器，提供 x64 和 ARM64 版本；缺少 .NET 10 桌面运行时时会提示并联网下载，已有兼容运行时则直接安装。

## 安装与升级

macOS：下载 `ChirpOS-0.7.1-macOS-arm64.zip`，退出旧应用后替换“应用程序”中的 ChirpOS。适用于 Apple Silicon、macOS 13 及以上；正式包使用 Developer ID 签名并通过 Apple 公证。

Windows：下载对应架构的 `ChirpOS-0.7.1-win-x64-setup.exe` 或 `ChirpOS-0.7.1-win-arm64-setup.exe`。从 v0.7.0 或更早版本升级，**需手动运行一次新安装器**，旧版自动更新器无法迁移到新包格式。设置和观鸟记录会保留。安装运行时可能请求管理员权限；Windows 程序尚未使用发布者证书签名。

`-framework-dependent.zip` 仅供新版自动更新器使用，不是首次安装入口。`SHA256SUMS.txt` 提供各安装包的校验值。

## English

- Quickly double-click a bird in birdwatching mode to pop three hearts above its head, then let them float away. An existing name label immediately moves just above the initial hearts and continues its original animation. Repeated clicks no longer create duplicate labels.
- Expanded hit areas for small birds. Fixed name-label and click-effect positioning near the top of the screen, and Windows flickering caused by hearts and labels repeatedly changing their stacking order.
- Added Life List sorting tabs for first discovery time and observation count. Click the active tab again to reverse the direction; an arrow shows the current order. Unrecorded species always remain last.
- Changed the English first-discovery message to “Lifer” with a separator after the bird’s name.
- Refined silhouettes, plumage, and flight proportions, especially for larger birds. Fixed folded-wing markings appearing before landing wings finish folding, and missing visible flight feet on the Ruddy Shelduck and other species.
- Made circling occasional and limited it to two laps.
- Introduced lightweight Windows installers for x64 and ARM64. Setup offers to download .NET 10 Desktop Runtime when needed and reuses compatible existing runtimes.

### Installation and upgrades

macOS: download `ChirpOS-0.7.1-macOS-arm64.zip`, quit the old app, and replace ChirpOS in Applications. Supports Apple Silicon on macOS 13 or later. The release is Developer ID-signed and Apple-notarized.

Windows: run `ChirpOS-0.7.1-win-x64-setup.exe` or `ChirpOS-0.7.1-win-arm64-setup.exe`. **Users upgrading from v0.7.0 or earlier must run the new installer manually once**; the old updater cannot migrate to the new package format. Settings and observations are preserved. Runtime installation may request administrator permission. Windows binaries remain unsigned.

The `-framework-dependent.zip` files are for the new automatic updater, not initial installation. Package checksums are included in `SHA256SUMS.txt`.
