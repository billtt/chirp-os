# 啾啾 v0.8.0

## 中文

- 鸟种从 100 种扩充到 120 种：黑枕黄鹂、寿带、栗喉蜂虎、三宝鸟、蓝翡翠、太平鸟、戴菊、黄雀、燕雀、普通朱雀、黄喉鹀、灰鹡鸰、松鸦、红交嘴雀、鸳鸯、反嘴鹬、白胸苦恶鸟、红腹锦鸡、丹顶鹤、朱鹮。
- 新鸟各有外形、羽色、习性动作与飞行节奏，包含寿带双飘尾、鸳鸯帆羽、反嘴鹬扫嘴、红交嘴雀交叉嘴和鹤类伸颈飞姿。
- 体长设置上限扩展至 160 cm，容纳丹顶鹤；保留现有非线性缩放方式。
- 旧设置沿用新增鸟种分配提示，保留原概率、锁定、自定义参数和观鸟记录。macOS 与 Windows 共用新增图集。

## English

- Expanded the catalog from 100 to 120 birds, with distinct anatomy, field marks, perched actions and flight timing for every addition.
- Highlights include the paradise flycatcher's twin tail ribbons, Mandarin Duck's folded-wing sails, avocet bill sweeping, crossed mandibles and the crane's extended-neck flight.
- Adult-length settings now allow up to 160 cm for the Red-crowned Crane, using the existing size curve.
- Existing preferences use the new-species allocation prompt; probabilities, locks, custom behavior and Life List records retain the existing migration rules. Both platforms share the new atlases.

## 安装与升级 / Installation and upgrades

macOS：下载 `ChirpOS-0.8.0-macOS-arm64.zip`，退出旧应用后替换“应用程序”中的 ChirpOS。适用于 Apple Silicon、macOS 13 及以上；正式包使用 Developer ID 签名并通过 Apple 公证。

Windows：运行对应架构的 `ChirpOS-0.8.0-win-x64-setup.exe` 或 `ChirpOS-0.8.0-win-arm64-setup.exe`。缺少 .NET 10 桌面运行时时，安装器会提示并联网下载；运行时安装可能请求管理员权限。**从 v0.7.0 或更早版本升级，需手动运行一次新安装器**，旧版自动更新器无法迁移到新包格式。设置和观鸟记录会保留。Windows 程序尚未使用发布者证书签名。

macOS: download `ChirpOS-0.8.0-macOS-arm64.zip`, quit the old app, and replace ChirpOS in Applications. Supports Apple Silicon on macOS 13 or later. The release is Developer ID-signed and Apple-notarized.

Windows: run `ChirpOS-0.8.0-win-x64-setup.exe` or `ChirpOS-0.8.0-win-arm64-setup.exe`. Setup offers to download .NET 10 Desktop Runtime when needed; runtime installation may request administrator permission. **Users upgrading from v0.7.0 or earlier must run the new installer manually once**; the old updater cannot migrate to the new package format. Settings and observations are preserved. Windows binaries remain unsigned.

`-framework-dependent.zip` 仅供新版自动更新器使用，不是首次安装入口。`SHA256SUMS.txt` 提供各安装包的校验值。

The `-framework-dependent.zip` files are for the new automatic updater, not initial installation. Package checksums are included in `SHA256SUMS.txt`.
