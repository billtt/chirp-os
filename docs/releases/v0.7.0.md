# 啾啾 v0.7.0

- 鸟种扩充至 100 种，默认出现权重调整为面向中国全国范围。
- 新增观鸟模式：用取景框点击记录小鸟，同一次到访只记录一次，首次发现显示“加新！”并庆祝。
- 观鸟记录保存累计次数与首次发现日期；未发现鸟种显示无名称剪影。首次启动或从旧版升级会介绍并默认开启观鸟模式，可从菜单关闭。
- 设置改为左右分栏：通用、鸟种概率、鸟种设置。鸟群数量可在 5–20 只间调整，全局尺寸可在 1.0–2.0 倍间调整；观鸟模式仅禁用鸟种自定义设置，退出后恢复原配置。
- 观鸟记录采用紧凑的浅灰布局，在鸟旁显示次数。修复 Windows 布局、字体及文字裁切问题，并统一两端菜单。
- 修复鼠标追随飞行小鸟时的短暂卡顿，以及应用自身窗口未能遮挡小鸟的问题。
- 修复赤麻鸭颈环及其他鸟种的纹路越界，保留羽冠、角羽与饰羽。
- 移除暂停动画和“打开项目说明”菜单项，精简 README。

macOS 安装包已使用 Developer ID 签名并通过 Apple 公证。Windows 安装包分别提供 x64 和 ARM64，解压后运行 ChirpOS.exe，无需额外安装 .NET。设置和观鸟记录会保留。

## English

- Expanded the catalog to 100 species, with default arrival weights covering birds across China.
- Added birdwatching mode: click birds through a viewfinder, record each visitor once, and celebrate newly discovered species.
- The Life List preserves observation counts and first discovery dates. Undiscovered species remain unnamed silhouettes. New installations and upgrades introduce and enable the mode; it can be disabled from the menu.
- Redesigned Settings with General, Species probabilities, and Species settings sections. Choose 5–20 birds and a global size of 1.0–2.0×. Birdwatching mode disables species customization while preserving your preferences for later.
- Made the Life List more compact with a light gray background and counts beside birds. Fixed Windows layout, font sizing, and clipped text, and aligned menus across platforms.
- Fixed brief freezes when following flying birds with the pointer and occlusion by the app’s own windows.
- Fixed the Ruddy Shelduck neck ring and overflowing plumage marks while retaining projecting crests and ornamental feathers.
- Removed animation pause and the project-description menu item, and simplified the README.

The macOS package is Developer ID-signed and notarized by Apple. Windows packages are available for x64 and ARM64: extract and run ChirpOS.exe without a separate .NET installation. Existing settings and observations are preserved.
