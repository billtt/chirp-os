## 中文

- 鸟种总数增至 46 种，新增领角鸮、斑头鸺鹠和纵纹腹小鸮；分别具有耳羽簇、圆头横斑、白眉纵纹等识别特征，以及前倾、转头、点头动作。
- 逐一优化原有 43 种鸟的身体比例、头嘴、尾部、翅形和关键羽色，强化相似鸟种的区别。
- 各鸟种采用独立的动作节奏，增加探食、翘尾、抬脚、张翼、啄击等姿态；区分短圆翅、尖翅和猛禽滑翔外观。
- 图鉴按各鸟种自身速度播放动作；macOS 与 Windows 共用更新后的 1,242 张图集帧。
- 升级保留已有概率、锁定状态及自定义设置。首次启动时会提示如何分配三种新鸟的出现概率；选择手动设置时，新鸟默认不出现。

## English

- Adds Collared Scops Owl, Asian Barred Owlet and Little Owl, bringing the catalog to 46 species. Each has distinct plumage, proportions and characteristic poses.
- Refines the original 43 species with individual body, head, bill, tail and wing shapes and clearer field marks.
- Introduces individual action schedules for probing, tail flicking, stepping, wing stretching and pecking, plus differentiated rounded wings, pointed wings and soaring poses.
- Updates the gallery playback and shared artwork across macOS and Windows: 1,242 atlas frames.
- Preserves existing probabilities, locks and custom settings. On first launch, choose how to allocate probabilities to the three new species; manual configuration leaves them disabled initially.

Quit the previous version before updating. The Apple Silicon macOS build is Developer ID-signed and notarized. Windows ARM64 and x64 ZIPs are self-contained; extract and run ChirpOS.exe. Windows binaries remain unsigned.

Validation: 52 macOS core tests, 13 desktop integration checks, 234 Windows core checks, all-species image validation and cross-platform schedule/atlas parity passed. Windows desktop testing was not performed. Animation timings are artistic interpretations, not field-measured behavior frequencies.
